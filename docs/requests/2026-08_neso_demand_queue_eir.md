# EIR — NESO, the demand queue in aggregate

**To:** InformationRights@neso.energy.
**Status:** DRAFT — not sent. Rewritten 2026-09-16. The August version
of this file asked for the demand connection queue at project level;
that is what FOI/26/165 refused on 10 September 2026 (transcribed beside
this file), and the internal review of that refusal is where the
argument for project-level fields is made. This version asks NESO for
the form of information its disclosure log shows it gives: counts,
megawatt bands, months and zones, with no names. Send it separately from
the review; NESO treats a refined request as a new one, with its own
20-working-day clock.
**Why this shape:** across thirteen responses on demand connections in
NESO's log (`data/external_sources/neso_disclosure_log/`), every request
for a list was refused as manifestly unreasonable under regulation
12(4)(b), and every request for a count or a distribution was answered —
FOI/26/121 and FOI/25/294 gave battery-to-data-centre modifications by
size and month, FOI/26/113 gave transmission demand by firm connection
year. NESO's Connections team already holds the IRN responses as a
structured dataset (FOI/26/165 confirms it), so the tables below are
filters and sums on data NESO has, not a manual review of contracts.
**Framing:** Environmental Information Regulations 2004; NESO accepts
the information is environmental under regulation 2(1)(c) (FOI/26/165).
Sender details are Luke's.

---

Dear Information Rights team,

Under the Environmental Information Regulations 2004, please provide the following aggregated information. Nothing below asks for a project, customer or site to be named, and each table is a count and a sum over data NESO has confirmed it holds (FOI/26/165, 10 September 2026): the responses to the Demand Information Request Notice of March 2026 and the list of battery-storage agreements modified to include a data centre.

**1. Projects that answered the Information Request Notice as data centres.** For the transmission-connected demand projects that confirmed in their IRN response that the project is a data centre, the number of projects and their total contracted capacity in MW:

- (a) by size band, using the bands in Table 1 of Ofgem's Curate consultation (0–10, 10–50, 50–100, 100–500, 500 MW and above);
- (b) by transmission zone (T1 to T17), as NESO's Call for Input summary presents its own figures;
- (c) by queue status: pre-reform agreement, Gate 1, Gate 2 Phase 1, Gate 2 Phase 2, after Phase 2;
- (d) by firm or offered connection year, in the form of NESO's response FOI/26/113;
- (e) by the answer given to the IRN's financial-commitment question, in the form of page 5 of the Call for Input summary.

**2. The same five tables for the IRN respondents that did not confirm the project is a data centre**, so that the data-centre share of the queue can be read against the whole.

**3. Battery-storage agreements modified to include a data centre, Great Britain.** NESO has given the England and Wales figures (FOI/26/121) and the Scotland figures (FOI/25/294, internal review). Please provide, for the same contracted or granted modifications, and for any further ones contracted since those responses were compiled:

- (a) the number of projects and total capacity by transmission zone;
- (b) the number of projects and total capacity by month the modification application was received, and by month it was contracted;
- (c) the number and capacity of projects where the modification made the project a co-located battery and data centre, and the number where it replaced the battery entirely;
- (d) the number and capacity of such projects whose modified capacity falls in each of the Table 1 size bands.

**4. The Demand Information Request Notice Analysis.** The expected date of publication, and, if it is published before this request is answered, the document itself.

**5. The counts behind the IRN.** The number of Information Request Notices issued in March 2026, the number of responses received by the deadline, and the number received since.

Where a cell would contain fewer than three projects and NESO considers that a risk of identification, please suppress that cell and say so, rather than withholding the table. Please supply the tables as a spreadsheet (CSV or XLSX).

Yours faithfully,

[SENDER]
